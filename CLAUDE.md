# CLAUDE.md

## The redesign is live (M6 swap done, M7 complete)

This repo was rebuilt from a single-page carousel into a multi-page, blog-style portfolio with an
in-browser editor. **Before doing any work, read `docs/ROADMAP.md` and `docs/ARCHITECTURE.md`** - they hold
the milestone checklist, the frozen JSON schemas and module APIs, and the ground rules.

`index.html` is now the new home page. The old carousel lives in `Archived/Archived_carousel-index.html`
with its own copies of `newWebMain.js`, `projects.js`, `newWebStyle.css` and `navbar.css`; nothing in
`Archived/` is loaded by the live site, so treat it as a frozen snapshot rather than editing it.

Content is `content/projects.json` + `content/posts/<project>/<post>.json`, edited through `Editor/`
(changes stage into a localStorage queue and commit as one batch). Media derivatives are generated by
`tools/optimize-media.mjs` into `images/_derived/`; re-run it after adding images or video.
